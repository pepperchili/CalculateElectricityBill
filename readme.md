电费分摊助手 - 使用指南
我已经为您开发了一个基于 Web 的电费分摊计算程序。该程序严格按照“档位平分法”进行计算，并自动区分夏季和非夏季标准。

1. 功能特点
自动分档：根据月份自动判断夏季（5-10月）或非夏季（11-4月）标准。
档位减半：第一档、第二档的额度自动除以2，确保您只承担属于您的那一半低价额度。
公平计算：
您的费用 = 您的用量 × 阶梯电价（按半价额度算）
邻居费用 = 支付宝总缴费 - 您的费用
历史记录：所有计算结果都会保存在本地数据库中，随时可查。
2. 如何运行
第一步：准备环境
打开终端，进入项目目录：

cd /Users/lili/Documents/Pro/CalculateElectricityBill
第二步：安装依赖
如果您还没有安装 Flask，请运行：

python3 -m pip install flask
第三步：启动程序
python3 app.py
看到 Running on http://127.0.0.1:5001 字样后，在浏览器打开该链接。

3. 使用流程
首次使用（初始化）
第一次使用时，系统不知道您上个月的电表读数。

在“本月读数”中输入您上个月的抄表数（例如 1000）。
“支付宝缴纳总金额”填 0。
点击计算。这条记录将作为初始基准，不产生费用。
日常使用（每月）
从第二个月开始：

月份：选择当前账单月份。
本月读数：输入您家门口电表的当前读数（例如 1229.86）。
系统会自动减去上月读数，算出您的实际用量（229.86度）。
总金额：输入支付宝缴纳的电费总额（例如 136.56）。
查看结果：
表格中会显示“我应付”和“邻居应付”。
点击“查看计算详情”可以看到详细的阶梯计算过程（例如：第一档用了多少度，第二档用了多少度）。
